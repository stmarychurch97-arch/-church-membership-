================================================================
  برنامج عضوية كنسية — دليل التشغيل وبناء المثبت على Windows
================================================================

ملاحظة هامة:
هذا الأرشيف يحتوي على الكود المصدري الكامل لتطبيق سطح المكتب
(Python + PyQt6 + SQLite) وأدوات البناء التلقائية على نظام Windows.

أسهل طريقتين للتشغيل بعد فك الضغط (Extract All):

1) للتشغيل الفوري وإنشاء أيقونة على سطح المكتب:
   اضغط نقرتين على الملف:
   Install_Desktop_Shortcut.bat
   (سيقوم تلقائيًا بتثبيت المكتبات، إنشاء اختصار "عضوية كنسية"
   على سطح المكتب، وتشغيل البرنامج فورًا بدون إنترنت بعد ذلك).

2) لبناء ملف تنفيذي مستقل (ChurchMembership.exe) ومثبت (Setup.exe):
   اضغط نقرتين على الملف:
   Build_Windows_Installer.bat
   - ينتج مجلد: dist\ChurchMembership\ChurchMembership.exe
   - وإذا كان Inno Setup 6 مثبتًا ينتج:
     dist_installer\Setup_ChurchMembership_v1.0.exe

بيانات الدخول الافتراضية للتجربة:
- مدير النظام: admin  /  كلمة المرور: admin123
- مدخل بيانات: entry  /  كلمة المرور: entry123

ملاحظة بديلة:
يمكنك أيضًا تثبيت نسخة الويب من البرنامج مباشرة كتطبيق سطح مكتب
يعمل بدون إنترنت على Windows من خلال متصفح Edge أو Chrome
عبر زر "تثبيت كتطبيق على Windows" داخل البرنامج.
